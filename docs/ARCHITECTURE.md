# Архитектура

Коротко: **матч** считает бой, **режим** задаёт правила, **контроллеры** управляют бойцами, **движок** всё это показывает.

```
            ┌──────────── контроллеры ────────────┐
 джойстик → │ local   bot (bot.js)   remote (сеть) │ → команда { moveX, moveZ, aimDir, attack, ult }
            └──────────────────────────────────────┘
                                │
                                ▼
 режим (src/modes/*) ──► МАТЧ (src/game/match.js) ──► события: урон, смерть, звук, конец матча
   кто на арене,          бойцы, приёмы героев,                    │
   счёт, победа           снаряды, столкновения                    ▼
                                                   ДВИЖОК (src/game/engine.js): 3D, камера,
                                                   прицел, полоски ХП, звук → HUD в React (src/ui)
```

## Матч — `src/game/match.js`
- Хранит бойцов, снаряды, опасные зоны, время.
- `match.step(dt, controllers)` — один шаг боя: команды → движение и приёмы → столкновения → снаряды → смерти и возрождения → правила режима.
- Ничего не рисует и не играет. Всё, что должен увидеть или услышать игрок, кладёт в `match.events`: `damage`, `death`, `respawn`, `sfx`, `say`, `finish`.
- Конец матча — `match.finish({ winners, places, reason })`.

## Режимы — `src/modes/<id>.js`
Режим — объект с `setup`, `update`, `onDeath`, `hud`. Интерфейс описан в `src/modes/index.js`. Каждый файл — отдельный режим, они собираются сами и появляются в меню.

## Контроллеры — `src/game/controllers.js`
Кто управляет бойцом. У всех один метод: `command(dt, world)` возвращает команду кадра.
- `local` — джойстик и кнопки этого устройства.
- `bot` — бот (`src/game/bot.js`).
- `remote` — игрок по сети: последняя присланная команда движения и очередь ударов и ульт.

Команда — простой объект без ссылок, её можно переслать как JSON.

## Мультиплеер — «1 на 1 с другом»
```
 телефон A ──команды──►  СЕРВЕР (server/, Node + ws)  ◄──команды── телефон B
          ◄──снимки 30/с──  createMatch + режим online  ──снимки 30/с──►
```
- **Сервер авторитетный** (`server/index.js`). Он запускает тот же `createMatch` и те же приёмы героев, что игра: сборка `npm run build:server` кладёт `src/game`, `src/heroes`, `src/modes` и three.js в один файл. Сцена на сервере — пустая группа, эффекты — пустышки. Комнаты с кодом из 4 символов, до двух игроков.
- **Протокол** — `src/net/protocol.js`: сообщения JSON, команда бойца (`encodeCmd` / `decodeCmd`), состояние бойца в снимке (`encodeFighter`), режим `createOnlineMode` (правила дуэли, оба бойца — люди).
- **Игра** (`src/net/client.js` — соединение, `src/net/sync.js` — синхронизация). Движок считает у себя копию матча только для картинки: анимации, снаряды, эффекты, звуки.
  - ХП, смерти, возрождения, статусы, захват и счёт берутся из снимков; урон на устройстве — только вспышка, цифры урона приходят с сервера.
  - **Соперник** рисуется на 100 мс в прошлом, между двумя снимками (интерполяция); его удары и ульты приходят событиями и проигрываются его же приёмами.
  - **Свой боец** двигается сразу по джойстику (предсказание). Каждая команда пронумерована; сервер в снимке сообщает номер последней применённой (`ack`) и позицию, игра сравнивает её со своим предсказанием для того же номера и плавно убирает разницу (прыжком — если больше 2,5 м).
  - Игрок на севере видит арену с другой стороны: камера и оси джойстика перевёрнуты (`flip`).
- Бой с другом не меняет уток (дружеский).
- Развёртывание — `server/README.md`.

Что дальше можно добавить тем же путём: 2 на 2 и «каждый сам за себя» по сети (другой режим в `createOnlineMode`, у сервера — своя карта на комнату), подбор случайного соперника.
