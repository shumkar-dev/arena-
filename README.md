# Всадники Арены

Мобильная 3D-арена в блочном стиле для игры с друзьями (референс — Brawl Stars).
Полный дизайн-документ: [docs/GDD.md](docs/GDD.md).

**Играть:** https://shumkar-dev.github.io/arena-/ (телефон, горизонтально)

## Статус — этап 9: рейтинг + игра с другом по сети
- **1 на 1 (дуэль)** — ты против бота, бой до 3 убийств, счёт вверху, в конце «Победа» / «Поражение» с кнопками «Ещё раз» и «В меню». Без аптечек и усилителей.
- **2 на 2 «Султан чай»** — ты и бот-союзник против двух ботов. На базах стоят по две бутылки «Султан чая» с ХП, кто первым разобьёт бутылки врага — победил. На карте сигареты-усилители (🚬 удары на 35% больнее 10 с). Боты делятся на защитников и нападающих.
- **Каждый сам за себя** — четыре бойца в парке, до последнего выжившего, без возрождения. По дорожкам гуляют прохожие: их можно бить, они мешают пройти и ловят снаряды — живое укрытие. Есть аптечки (+1500 ХП) и сигареты. В итоге — занятое место.
- **Тренировка** — неподвижный манекен, без счёта.
- **Играть с другом** — все три режима по сети: создать комнату → код из 4 символов → друзья входят по коду → в лобби создатель выбирает режим (1 на 1, 2 на 2 или каждый сам за себя, можно менять до старта), каждый выбирает героя и в 2 на 2 — команду → создатель жмёт «Старт». После боя все возвращаются в то же лобби. Свободные места занимают боты. Бутылки, сигареты, аптечки и прохожие — как в обычной игре, утки — по тем же правилам. Бой считает свой сервер (`server/`), у телефонов — предсказание своего движения и плавные остальные. Установка сервера — [server/README.md](server/README.md).
- Меню в тёмно-красной гамме в стиле Brawl Stars: главный экран с героем на подиуме и кнопкой «Играть», выбор режима карточками, выбор героя (3D-модель на подиуме — можно покрутить пальцем, описание атак и ульты, кнопка «Баланс»), настройки (звук, громкость, ник, графика). Выбор запоминается.
- **Рейтинг — утки и звания** строго по GDD: 1 на 1 ±5, 2 на 2 +8/−4, «сам за себя» +10 (+5 за больше всех убийств) / +3 / 0 / −4. Утки не уходят ниже 0. Звания: Новичок, Таш, Кирпич, Брутал, Менталист, Король, Император. Экран «Рейтинг»: утка-трофей (блочная версия фигурки автора, `reference/`), лестница званий, таблица. Десять ботов с игровыми никами — постоянные участники таблицы со своими утками, в матчах получают награду по тем же правилам; соперники подбираются твоего уровня. Чем выше твоё звание, тем сильнее боты (реакция, прицел, упреждение, уклонение, укрытия, ульты).
- Боты за любого героя: уклоняются, прячутся за укрытия, стреляют с упреждением, копят серию на третью атаку и бросают ульту.
- Прицел как в Brawl Stars: касание — автоприцел, оттяжка кнопки — линия или сектор на земле. Серию сбрасывает пауза 2,2 с без атак.
- При первом входе игра просит ник (сменить — в настройках); он виден над героем и в рейтинге.
- На телефоне игра сама уходит в полноэкранный горизонтальный режим; если браузер не даёт (например, Safari на iPhone) — экран «Поверни телефон».
- Процедурные звуки (Web Audio), голоса героев и музыка — кнопка вкл/выкл справа вверху, три ползунка громкости в настройках.
- Архитектура под будущий мультиплеер — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Таблица рейтинга (Supabase)
Без настройки рейтинг хранится на устройстве. Чтобы таблица стала общей:
1. В Supabase: **SQL Editor** → вставить [docs/supabase.sql](docs/supabase.sql) → **Run**.
2. **Project Settings → API Keys**: скопировать *Project URL* (`https://<id>.supabase.co`, хвост `/rest/v1/` можно не убирать) и ключ *publishable* (`sb_publishable_…`; старый *anon public* тоже подойдёт).
3. На GitHub: **Settings → Secrets and variables → Actions → Variables** → добавить `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`. После следующего деплоя таблица общая: на экране «Рейтинг» справа вверху — «Общая таблица», при ошибке там же виден её код.
Для локальной разработки — те же две строки в файле `.env.local`.

Ключ *publishable* / *anon* публичный (он всё равно виден в коде страницы): писать в таблицу напрямую нельзя, утки меняются только через функцию `arena_add_ducks`, не больше чем на 15 за раз.

## Голоса и музыка
- `public/voices/<голос>_<событие>.mp3` — реплики героев. `<голос>` — `id` героя или поле `voice` в его `index.js` (у Гаргашмеля — `garga`). События: `select` (выбор героя), `start` (начало боя), `attack` (раз в 3–4 удара), `ult`, `hurt` (не чаще раза в 4 с), `kill`, `death`, `win`. Реплики не накладываются; важная (победа, смерть, убийство) перебивает менее важную. Нет файла — тишина (пока так у Шабы и у реплики смерти Гаргашмеля).
- `public/music/menu.mp3` и `battle.mp3` — музыка меню и боя, по кругу, с плавным переходом. Музыка — фон: при том же положении ползунка на ~9 дБ тише голосов и звуков, а пока звучит реплика героя, приглушается ещё. На нуле останавливается.
- В настройках — три ползунка: звуки, голоса, музыка; кнопка 🔊 выключает всё.
- Новые файлы: положить исходники `<голос>_<событие>.mp3` (и `music_menu.mp3`, `music_battle.mp3`) в любую папку и запустить `scripts/audio.sh <папка>` — обрежет тишину, выровняет громкость и сожмёт в `public/`. Нужен ffmpeg.

## Баланс
Таблица героев — [docs/BALANCE.md](docs/BALANCE.md). Она собирается из папок героев командой `npm run balance`. В игре та же таблица открывается кнопкой «Баланс» на экране выбора.

## Разработка
```bash
npm install
npm run dev       # доступно в локальной сети — можно открыть с телефона
npm run build
npm run balance   # пересобрать docs/BALANCE.md
npm run server    # собрать и запустить игровой сервер на :3001
```
На компьютере: WASD/стрелки — движение, J/пробел — удар, K — ульта (прицельная — в ближайшего врага), H — ударить себя на 1000 (проверка смерти).

Параметры адреса для отладки:
| Параметр | Что делает |
|---|---|
| `?mode=duel` | режим (`duel`, `teams`, `ffa`, `training`) |
| `?hero=izyum` | сразу на арену этим героем (`shaba`, `smitana`, `izyum`, `gargashmel`) |
| `?bot=shaba` | бот играет этим героем (без параметра — случайным) |
| `?dummy` | то же, что `?mode=training` — манекен |
| `?autoplay` | за игрока тоже играет бот — смотреть бой бот против бота |
| `?fast=4` | ускорить симуляцию в 4 раза |
| `?ws=ws://localhost:3001` | адрес игрового сервера (по умолчанию `wss://vsadniki.duckdns.org/arena-ws`) |
| `?debug` | матч в консоли: `window.__game` (`match`, `fighters`, `world`, `projectiles`) |

## Структура
- `src/heroes/<id>/` — **один герой — одна папка**:
  - `model.js` — блочная модель и анимации;
  - `kit.js` — приёмы и числа (объект характеристик);
  - `index.js` — описание: имя, роль, цвет, иконки, строки баланса, как им играет бот.
- `src/heroes/index.js` — сам собирает всех героев из папок. `src/heroes/blocks.js` — общие кубики и позы для моделей.
- `src/characters/` — исходные превью моделей автора (`*-blocky.jsx`), манекен, бутылка, предметы, прохожие, утка.
- `src/maps/<id>.js` — карты: дорога и парк (размеры, укрытия, точки старта, маршруты прохожих).
- `src/modes/<id>.js` — **один режим — один файл**: кто на арене, счёт, победа. Собираются сами (`src/modes/index.js`).
- `src/game/` — матч (`match.js`), контроллеры бойцов (`controllers.js`), отображение (`engine.js`), бот (`bot.js`), карта (`arena.js`), бойцы с ХП и статусами (`fighter.js`), цели, серия и снаряды (`combat.js`), прицел на земле (`aim.js`), эффекты (`effects.js`), звук (`sound.js`), голоса (`voice.js`), музыка (`music.js`), полоски ХП и цифры урона (`overlay.js`).
- `src/rating/` — утки и звания (`ranks.js`: награды, звания, сила ботов по званию), хранение и таблица (`store.js`: устройство + Supabase).
- `src/ui/` — экран боя (`Arena.jsx`), итог матча, джойстик, кнопки; `src/ui/menu/` — главный экран, режимы, герои, настройки, подиум героя (`HeroStage.jsx`); `src/ui/prefs.js` — сохранённые настройки.
- `src/net/` — сетевая игра: протокол (общий с сервером), соединение, синхронизация.
- `server/` — игровой сервер (Node + WebSocket, Docker).
- `scripts/balance.mjs` — сборка таблицы баланса; `scripts/audio.sh` — подготовка голосов и музыки.

## Как добавить нового героя
1. Создай папку `src/heroes/<id>/`, где `<id>` — латиницей, например `src/heroes/kolbasa/`. Проще всего скопировать папку похожего героя: ближник — `shaba` или `gargashmel`, стрелок — `smitana` или `izyum`.
2. **`model.js`** — функция, которая возвращает `{ root, animate }`:
   - `root` — группа Three.js, герой смотрит в +Z и стоит на земле (y = 0);
   - `animate(state)` вызывается каждый кадр. В `state` приходят `t`, `stride`, `moving` и всё, что вернул `pose()` из приёмов.

   Кубики и типовые позы (бег, стойка, выброс руки) — в `src/heroes/blocks.js`.
3. **`kit.js`** — объект характеристик (как минимум `maxHp`, `speed`, `ultCooldown`) и функция `createKit(me)`. Она возвращает приёмы:
   - `attack(dir)` — атака: `dir` = `{ x, z }` с прицела или `null` (автоприцел);
   - `ult(aim, world)` — ульта; `aim` = точка на земле или `null`;
   - `update(dt, world)` — логика каждый кадр;
   - `pose()` — состояние для `animate`;
   - `hud()` — `{ combo, ultCd, ultFrac, ultActive }` для кнопок;
   - `attackShape()` — форма прицела атаки: `line` / `cone`;
   - `ultAim: 'tap' | 'drag'`, а для `drag` ещё `ultRange` и `ultShape`;
   - по желанию: `lockFacing`, `busy`, `speedMul`, `activeArea()`.

   Серия атак, поиск целей, снаряды и укрытия — готовые функции в `src/game/combat.js`: `createChain`, `aimAttack`, `enemiesInCone`, `world.projectiles.spawn`, `lineClear`.
4. **`index.js`** — описание героя, `export default { … }`:
   - `id`, `order` (место в списке), `name`, `role`, `about`, `color`;
   - `icons: { attack, special }`;
   - `stats` — объект характеристик из `kit.js`;
   - `createModel`, `createKit`;
   - `balance: { attack, special, ult }` — строки для таблицы баланса, собирай их из чисел `stats`;
   - `bot` — как играет бот: `melee`, `range` (с какой дистанции бьёт), `keep` (где держится), `projectileSpeed` (для упреждения), `ult: { range, lead?, stream? }`.

   Если поля не хватает, игра при запуске назовёт, какого.
5. Запусти `npm run balance` — герой появится в `docs/BALANCE.md`. В выборе героя, в таблице «Баланс» и у ботов он появится сам.
