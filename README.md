# Всадники Арены

Мобильная 3D-арена в блочном стиле для игры с друзьями (референс — Brawl Stars).
Полный дизайн-документ: [docs/GDD.md](docs/GDD.md).

**Играть:** https://shumkar-dev.github.io/arena-/ (телефон, горизонтально)

## Статус — этап 1
- Карта «Дорога» с укрытиями (машины, бетонные блоки, ящики), столкновения.
- Шаба бегает: плавающий джойстик слева, камера сверху-сзади следует за игроком.
- Кнопка атаки (удар рукой) и ульта (баран, +50% скорости, 5 с, перезарядка 20 с) — пока без урона.
- PWA: манифест, иконки, офлайн-кэш, полноэкранный горизонтальный режим.

## Разработка
```bash
npm install
npm run dev      # доступно в локальной сети — можно открыть с телефона
npm run build
```
На компьютере: WASD/стрелки — движение, J/пробел — удар, K — ульта.

## Структура
- `src/characters/` — модели персонажей. `*-blocky.jsx` — исходные превью, `shaba.js` — игровая модель.
- `src/game/` — игровой цикл (`engine.js`) и карта (`arena.js`).
- `src/ui/` — джойстик и кнопки.

## Деплой
GitHub Actions собирает и публикует на GitHub Pages при каждом пуше в `main`.
Один раз в настройках репозитория: **Settings → Pages → Source: GitHub Actions**.
