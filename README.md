# Всадники Арены

Мобильная 3D-арена в блочном стиле для игры с друзьями (референс — Brawl Stars).
Полный дизайн-документ: [docs/GDD.md](docs/GDD.md).

**Играть:** https://shumkar-dev.github.io/arena-/ (телефон, горизонтально)

## Статус — этап 3
- Четыре героя по таблице GDD, выбор героя перед ареной (простой экран, красивое меню — на этапе 8).
- Серия атак: после двух попаданий третья атака особая, промах сбрасывает серию.
- Снаряды упираются в укрытия. Статусы над полоской ХП: 🐌 замедление, ⚡ ускоренная атака.
- ХП, полоски над головой, цифры урона, смерть и возрождение через 3 с. Манекен для тренировки.
- Фиксированный джойстик. PWA, полноэкранный горизонтальный режим.

### Баланс (у всех 4000 ХП, скорость 5,5, ульта — 20 с)
| Герой | Атака | 3-я атака | Ульта |
|---|---|---|---|
| Шаба | удар 600, вблизи | захват 2 с, 4 × 300 | баран 5 с: +50% скорости и урона |
| Смитана | сметана 480, дальность 7,5 | 480 + замедление 45% на 3 с | мотоцикл 5 с: 260 всем в радиусе 2,4 каждые 0,5 с |
| Чёрный Изюм | изюминка 380, дальность 10,5 | взрыв 700 в радиусе 1,9 | 3 с на земле: рывок к врагу в радиусе 6,5 и удары по 250 каждые 0,28 с |
| Гаргашмель | щупальце 520, вблизи, всем в конусе | удар + атака вдвое быстрее 4 с | шмель: мгновенный взрыв 1800 в радиусе 2,6, дальность 9 |

Числа лежат в `src/game/kits/*.js` (объекты `SHABA`, `SMITANA`, `IZYUM`, `GARGASHMEL`).

## Разработка
```bash
npm install
npm run dev      # доступно в локальной сети — можно открыть с телефона
npm run build
```
На компьютере: WASD/стрелки — движение, J/пробел — удар, K — ульта (у Гаргашмеля — в ближайшего врага), H — ударить себя на 1000 (проверка смерти).
`?hero=izyum` в адресе — сразу на арену нужным героем (`shaba`, `smitana`, `izyum`, `gargashmel`), `?debug` открывает бойцов в консоли как `window.__game.fighters`.

## Структура
- `src/characters/` — модели. `*-blocky.jsx` — исходные превью автора, `shaba.js`, `smitana.js`, `izyum.js`, `gargashmel.js`, `dummy.js` — игровые модели, `blocks.js` — общие кубики и позы.
- `src/game/heroes.js` — список героев: модель, приёмы, иконки, описание.
- `src/game/kits/` — приёмы героев и их числа.
- `src/game/` — игровой цикл (`engine.js`), карта (`arena.js`), бойцы с ХП и статусами (`fighter.js`), цели и снаряды (`combat.js`), эффекты (`effects.js`), полоски ХП и цифры урона (`overlay.js`).
- `src/ui/` — выбор героя, джойстик, кнопки.
