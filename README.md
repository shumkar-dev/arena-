# Всадники Арены

Мобильная 3D-арена в блочном стиле для игры с друзьями (референс — Brawl Stars).
Полный дизайн-документ: [docs/GDD.md](docs/GDD.md).

**Играть:** https://shumkar-dev.github.io/arena/ (телефон, горизонтально)

## Статус — этап 2
- Карта «Дорога» с укрытиями (машины, бетонные блоки, ящики), столкновения.
- Шаба: серия «удар — удар — захват». Захват держит врага 2 с и бьёт 4 раза. Ульта — баран: +50% скорости и урона на 5 с, перезарядка 20 с.
- ХП у бойцов, полоска над головой, всплывающие цифры урона.
- Манекен для тренировки. Смерть и возрождение через 3 с.
- Фиксированный джойстик в левом нижнем углу.
- PWA: манифест, иконки, офлайн-кэш, полноэкранный горизонтальный режим.

## Разработка
```bash
npm install
npm run dev      # доступно в локальной сети — можно открыть с телефона
npm run build
```
На компьютере: WASD/стрелки — движение, J/пробел — удар, K — ульта, H — ударить себя на 1000 (проверка смерти).
`?debug` в адресе открывает бойцов в консоли как `window.__game.fighters`.

## Структура
- `src/characters/` — модели персонажей. `*-blocky.jsx` — исходные превью, `shaba.js` — игровая модель.
- `src/characters/dummy.js` — тренировочный манекен.
- `src/game/` — игровой цикл (`engine.js`), карта (`arena.js`), бойцы с ХП и смертью (`fighter.js`), полоски ХП и цифры урона (`overlay.js`).
- `src/game/kits/` — приёмы персонажей (`shaba.js`).
- `src/ui/` — джойстик и кнопки.
